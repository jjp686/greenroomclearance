# Green Room Clearance — Commercial AV & IT Stock Clearance

> **Commercial Stock Clearance Made Simple**  
> Professional clearance and resale of surplus office and AV equipment across Bournemouth, Christchurch and Poole.

---

## Overview

Green Room Clearance works with local businesses, corporate offices, MSPs, AV integrators, and commercial premises across **Bournemouth, Christchurch & Poole (BCP)** to recover value from unused workplace technology and surplus stock.

### Key Capabilities
- **Meeting Room & AV Equipment**: Video bars, commercial displays, Crestron/Extron hardware, audio systems.
- **Office IT Hardware**: Laptops, desktop PCs, monitors, docking stations, network switches, and server racks.
- **Surplus Stock & Returns**: Overstock, commercial returns, cancelled order stock.
- **End of Lease Office Clearances**: Fast, turnkey decommissioning ahead of lease handover.
- **Technology Asset Recovery**: Professional valuation, remarketing, and circular economy resale.

## Local Development

To run the site locally:

```bash
# Option 1: Python HTTP server
python3 -m http.server 8088

# Option 2: Node.js (npx serve)
npx serve .
```

Then visit [http://localhost:8088](http://localhost:8088) in any browser.

## Deployment

This is a clean, lightweight static web application requiring zero build steps or external dependencies. It can be hosted directly on:
- **GitHub Pages** (Settings -> Pages -> Deploy from branch `main`)
- **Cloudflare Pages**
- **Netlify / Vercel**
- Or custom static hosting / S3 / Carrd custom domain.
